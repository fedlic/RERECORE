# RECORE OSS Clone (初期版)

RECOREのような**リユース業向け基幹システム**を、オープンソースとして再実装するためのスターターリポジトリです。

> 目的: 在庫管理・仕入/販売・顧客管理の基本機能を、誰でも拡張できる形で公開開発する。

## スコープ（MVP）

- 商品マスタ（SKU / JAN / コンディション / 販売価格）
- 在庫ロケーション管理（店舗 / 倉庫 / 棚）
- 仕入入力（単品・ロット）
- 販売入力（POS連携を想定したヘッドレスAPI）
- 顧客管理（会員ID・購入履歴）
- 監査ログ（だれが・いつ・何を変更したか）

詳細は `docs/mvp.md` を参照してください。

## ディレクトリ構成

- `docs/` - 仕様・設計メモ
- `openapi/` - API定義（OpenAPI 3.1）

## OSS方針

- ライセンス: MIT
- 設計優先: まず API 契約を固定し、その後実装を差し替え可能にする
- 将来計画: マルチテナント、権限管理、会計/EC連携

## 次のステップ

1. `openapi/recore-oss.yaml` をベースにバックエンド実装を追加
2. 在庫移動・棚卸のワークフローをAPI化
3. フロントエンド（Web POS / Backoffice）を分離モノレポで追加
